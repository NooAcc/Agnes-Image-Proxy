# 管理面板生图控制台设计

日期：2026-11-26

## 意图

在 Agnes-Image-Proxy 现有后台管理面板新增独立的“生图控制台”导航入口，允许管理员手动提交文生图或带参考图的生图请求，并直接查看最终图片，无需额外 API Key 或外部客户端。

## 用户明确的要求

- 至少提供提示词、参考图、模型、数量等配置。
- 配置可参考成熟开源项目；布局依据 https://github.com/Railgun19457/astrbot_plugin_image_generation 。
- 仅保留生图部分，不新增独立任务记录；历史由现有日志和图片功能承担。
- 右侧不显示任务状态，仅展示最终生成的图片。
- 右侧默认展示单张大图，使用数字按钮切换；移除该区域的下载和“作为参考图”操作。
- 将“作为参考图”添加到现有“图片”板块的图片详情中，紧邻“复制提示词”按钮。
- 允许破坏性变更，不需要旧版本代码、数据兼容或冗余设计。
- 必要时允许使用 UI 框架，但并未要求框架迁移。

## 布局

参考该项目 `frontend/src/views/GenerateView.vue` 的主体，而非移植其整个应用：

- 宽屏采用两张并排 outlined 卡片，左侧宽度 7/12，右侧 5/12。
- 左侧标题“创建生图”，标题行右侧为“开始生成”按钮。
- 左侧内容顺序：大提示词输入框；模型/数量/宽高比/分辨率紧凑参数行；折叠的更多尺寸设置；参考图输入与缩略图网格；表单错误和简短帮助文案。
- 右侧标题“生成图片”，只展示初始空态或单张最终图片的大图预览。图片使用 `object-fit: contain` 等比缩放、不裁切，预览区域充分使用右卡片宽度，限制高度以适应窗口；保持大图而不是小型缩略图。
- 多图时在大图下方展示从 1 开始的数字按钮，依据本次实际返回图片数量创建；成功后默认显示第一张，按钮切换选中图并标记 `aria-pressed` 或 `aria-current`。单图无需展示无意义的切换按钮。图片多时按钮可换行，不导致横向溢出。
- 右侧不提供下载或“作为参考图”；不额外增加结果缩略图网格或结果 lightbox。标题右侧可清空当前预览（不删除归档图片）。
- 现有“图片”板块的详情弹窗，在“复制提示词”之后、“下载”之前新增“作为参考图”按钮；保留原有下载、删除及其他详情行为。
- 不新增内部页签、任务历史区、状态徽章、进度条、请求耗时、任务取消或任务详情。
- 保留原后台导航、主题切换以及深浅色设计语言。中小屏参数行换行，窄屏两张卡片上下排列。
- 最新草图 v4：`.superpowers/brainstorm/1542-1795624674/content/generation-large-preview-v4.html`。大图中的 SVG 是明确标注的布局占位插画，非真实生成图，不带入产品；草图仅供结构和交互确认。

## 参数与默认行为（以下未被用户逐项指定，属于实现建议）

### 提示词

必填，提交时去除首尾空白；大文本框支持多行。提示词为空时不得发送请求。成功后不清空提示词或其他配置，方便微调及再次生成。

### 模型

从现有模型列表动态获取，不把另一项目的供应商或模型硬编码进界面。首次使用选列表第一项，用户可切换。默认列表当前是 `agnes-image-2.5-flash`、`agnes-image-2.1-flash`。不得为了生图修改全局探测模型设置。

### 数量

默认 1，正整数，复用现有 `n` 语义及后端验证，不任意增加与公共接口不一致的数量上限。本页同一时间只允许一项正在等待的提交，防止重复点击。

### 尺寸

默认采用设置中的 `defaultSize` 档位和 1:1 比例。

- 基础参数为 1K/2K/3K/4K 分辨率、1:1/3:4/4:3/16:9/9:16/2:3/3:2/21:9 宽高比。
- 展示所选档位与比例对应的预计像素尺寸，明确实际尺寸以上游为准。
- “更多尺寸设置”允许切换到跟随第一张参考图尺寸或自定义 WxH。
- 跟随参考图模式使用已有 `size=auto` 解析与参考图尺寸读取；缺少参考图时表单阻止提交。该模式隐藏/禁用独立比例，避免让用户误以为可同时覆盖参考图尺寸。
- 自定义尺寸按当前 `ResolveSize` 归一化到最近支持的档位及比例，不承诺精确 WxH 输出；该模式隐藏/禁用基础分辨率和比例控件，以 WxH 为唯一尺寸输入。
- 不修改现有上游尺寸语义，不将字面 auto 转发给不支持它的上游。

### 参考图

可选；不带参考图即文生图，带参考图复用当前参考图生图能力，无须再设“文生图/图生图”开关。

- 本地上传、多选、拖拽及剪贴板图片粘贴。
- 添加 HTTP(S) 图片 URL。
- 从现有图库选择原图；图库选择使用管理员鉴权原图读取，不依赖短期签名 URL 能否被上游回源，也不上传到新增独立存储。
- 本地文件和图库图片使用支持的 PNG/JPEG/WebP 字节转为现有接口支持的参考格式；复用后端限制：最多 16 张、单张最多 20 MiB、请求体最多 32 MiB。前端预检查，后端仍是最终验证边界，必须包含 Base64 膨胀及 JSON 开销。
- 缩略图显示名称、大小（已知时），可打开大图、移除、调整顺序；调整顺序可用向前/向后按钮，不强制引入拖拽库。
- 第一个参考图作为 auto 模式的尺寸来源。
- URL 格式错误、数量超限、类型不支持、体积超限均反馈明确错误。URL 网络/安全验证复用现有后端规则；前端预览失败不等于请求图不可用，不应绕过后端安全校验。
- 本地预览 object URL 在移除/清空/页面卸载时释放。

## 提交与结果

- 使用现有管理端认证保护的 `/admin/api/images/generations` 入口：沿用 `Auth.Admin` 的管理员 Cookie / 有效 Bearer 认证及 Cookie 变更请求的同源检查。界面只使用已有管理员会话，无需要求额外 API Key；不放宽现有 `/v1/images/*` 的数据面认证，也不新增仅此页面使用的认证分支。
- 管理入口复用现有参数解析、生图服务、账号池、输出交付、日志写入和归档。优先直接复用现有同步 `handleImageRequest`，只有路由与认证边界不同，不建立第二套生成服务或任务数据库。
- 模型复用现有 `/v1/models` 只读接口。页面请求已有 `b64_json` 输出并按原图签名识别 MIME，转换本地 Blob/object URL 大图预览；不放宽严格 CSP，也不依赖公共图片 origin 与后台同源。管理端接口继续支持原有 URL/Base64 两种交付模式。
- 一次点击发起一次同步请求，等待期间按钮显示“生成中…”且禁用重复提交，左表单配置/引用输入暂时禁用，避免正在生成的内容与表单不一致。右侧不显示等待状态：若有上一轮结果则保留，若无则维持空态。
- 成功后右侧替换为本次最终图片列表并默认显示第一张大图，仅通过数字按钮切换，不累积请求历史；请求数量不保证每张图片对应一个独立上游调用，遵循原服务结果语义。
- 失败时左侧显示后端可读错误，保留全部配置、参考图和上一轮成功图片，恢复提交按钮。
- 右侧结果仅大图展示和数字切换，无下载、转参考图按钮或新增结果 lightbox。需要下载时使用现有“图片”板块。
- 图库详情“作为参考图”动作：读取当前详情图片的受管理端认证保护的原图，按相同参考图验证规则检查并追加到生图控制台参考列表；成功后关闭详情并跳转生图控制台。不替换已有参考图、不覆盖提示词或其他生成配置，重复添加同一图库 ID 时复用已有参考项并反馈，避免误点击产生重复占位。原图读取或限制检查失败时保留弹窗及全部现有状态并显示错误；正在生图且表单禁用时禁止该操作。该跨板块行为为实现建议。
- 不新增独立图库或持久化结果模型。图库原有“复制提示词”“下载”“删除”不改变。
- “清空预览”只清空当前页面的输出，不调用删除图库接口。
- 同步请求不承诺刷新/关闭页面后仍能恢复当前右侧预览或继续完成正在执行的请求，遵循现有请求上下文取消语义；已经归档的输出及日志仍能在原功能查看。
- 表单不新增 localStorage 持久化，避免存储敏感提示词或大型参考图。本页状态保留在当前页面内，普通切换管理板块不重置。

## 技术选择（实现建议）

沿用 Go 后端及当前 TypeScript 生成静态 HTML/脚本的前端架构，新增单一 section，复用 runtime、api、主题 CSS、原图读取和对话框交互。此次不迁移 React/Vue/Vuetify，不新增 UI 框架、任务存储、数据库 schema 或兼容分支。布局借鉴参考项目，产品代码自行实现，不直接复制第三方业务代码。

`.superpowers/` 是本地草图辅助目录，加入 `.gitignore`。现有 `.codegraph/` 和已有未跟踪计划文件不触碰，不提交。

## 非目标

预设、人设、多供应商配置、负面提示词、Seed、步数、CFG、采样器、LoRA、ControlNet、参考图权重、图像局部编辑、取消任务、后台异步队列、任务历史、实时结果流、整个管理面板重写及旧数据迁移。

## 验收

- 从后台导航可进入生图控制台，布局符合 7:5 参考结构并兼容窄屏和深浅色。
- 基础参数、尺寸模式、多参考图可以组成后端接受的请求；字段错误与请求失败明确可见。
- 有效管理员会话可以生成，匿名请求、无效 Bearer 和跨源 Cookie 提交被拒绝；有效 Bearer 沿用既有管理端授权语义。既有公共接口仍不接受会话 Cookie。
- 图片、日志与归档复用原流程，不新增任务存储或状态 UI。
- 等待不产生右侧任务状态；失败不丢失配置及旧结果；成功仅展示最新最终图片。
- 本地上传、剪贴板、URL、图库选择、顺序调整及图库详情“作为参考图”在限制内可用；图库详情按钮紧邻“复制提示词”。
- 右侧默认第一张完整大图，多图可用数字按钮切换，成功重置到第一张；不显示缩略图、下载或“作为参考图”按钮。
- 预览清空不删除图库，图库原有大图、下载等功能不变。
- 后端路由、认证、解析和生成交付测试通过；前端构建、类型/格式校验、DOM 交互测试通过；不访问真实付费生图上游做自动化测试。
